# Earnings Call NLP Sentiment Signal

**Hypothesis:** Earnings calls with more positive language predict higher stock returns in the days following the call.

Using [FinBERT](https://huggingface.co/ProsusAI/finbert) — a BERT model fine-tuned on financial text — to score sentiment from S&P 500 earnings call transcripts, then testing whether that score predicts next-day and next-week excess returns.

## Methodology notes

- FinBERT has a 512-token limit, so transcripts are chunked into 400-character segments; the net sentiment score is averaged across the first 10 chunks.
- Returns are measured from market close on the call date to close 1 or 5 trading days later.
- OLS regression and quintile analysis are both reported; a noisy or weak signal is still informative — the goal is rigorous hypothesis testing, not a perfect result.
